## Purpose

How to define a brand's strategy and visual identity system before any logo or website design begins. Branding is the strategic layer (why the brand exists, how it's positioned, what it sounds like); the logo and visual system are downstream outputs of it — see `skills/design/logo-design/`.

## Core Concepts To Apply

- **Strategy before visuals**: define mission, target audience, brand personality (e.g. authoritative vs. playful), and competitive positioning before any logo sketch — a strong visual identity applied to unclear strategy just produces a good-looking, confused brand.
- **Brand as a system, not a fixed asset**: a 2026 brand identity is built from a flexible system (a stable logo, a "brand mood" rather than one fixed hex color, contextual variations for different platforms) rather than one static color palette locked forever — this allows the brand to adapt across web, mobile, print, and AI-mediated surfaces without losing recognizability.
- **Living documentation over static PDFs**: maintain brand guidelines as a continuously updated internal reference (even a well-organized page in this repo) rather than a one-time PDF that goes stale.
- **Accessibility built into the brand system**: choose brand colors and typography that pass contrast requirements from the start (see `skills/ui-ux/accessibility/`) — treating accessibility as core brand-system design rather than a late compliance pass.
- **Consistency across touchpoints**: every application of the brand — website, social, email, print — should trace back to the same strategy, voice, and visual rules; inconsistency is what erodes recognition fastest.
- **Authenticity over generic trend-chasing**: brands that reflect a real point of view, history, or locality tend to outperform ones built purely by following the current visual trend cycle — use trend awareness (see `skills/ui-ux/typography-color-2026/`, `skills/ui-ux/tactile-brutalism/`) as an input, not the foundation.
