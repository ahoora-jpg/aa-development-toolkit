# Database Design Sources

Verified 2026-07-24.

- [PostgreSQL: Indexes](https://www.postgresql.org/docs/current/indexes.html) — Current first-party documentation for index types, multicolumn behavior, and index tradeoffs.
- [PostgreSQL: Transaction Isolation](https://www.postgresql.org/docs/current/transaction-iso.html) — Current first-party definition of supported isolation behavior and anomalies.
- [PostgreSQL source](https://github.com/postgres/postgres) — Actively maintained upstream relational database implementation.
- [MongoDB Transactions](https://www.mongodb.com/docs/manual/core/transactions/) — First-party guidance on document-database transaction behavior and costs.
- [MongoDB Replication](https://www.mongodb.com/docs/manual/replication/) — First-party replica-set and consistency documentation.
- [Redis source](https://github.com/redis/redis) — Actively maintained upstream key-value/data-structure server used to verify cache and specialized-store terminology.
