# Authentication and Security Sources

Verified 2026-07-24.

- [OWASP Top 10: 2025](https://owasp.org/Top10/2025/) — Current authoritative OWASP awareness list for major web-application risk classes.
- [OWASP API Security Top 10: 2023](https://owasp.org/API-Security/editions/2023/en/0x11-t10/) — Current released OWASP API risk list with API-specific authorization and resource-abuse threats.
- [OWASP Application Security Verification Standard](https://github.com/OWASP/ASVS) — Actively maintained, testable security-requirements standard from OWASP.
- [RFC 9700: OAuth 2.0 Security Best Current Practice](https://www.rfc-editor.org/rfc/rfc9700.html) — IETF BCP that updates OAuth threat mitigations and deprecates unsafe modes.
- [OpenID Connect Core 1.0](https://openid.net/specs/openid-connect-core-1_0.html) — Normative specification for identity on top of OAuth 2.0.
- [OWASP Secrets Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) — Actionable OWASP guidance for storage, rotation, access, auditing, and lifecycle.
