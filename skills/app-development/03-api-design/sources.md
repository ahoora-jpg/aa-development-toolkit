# API Design Sources

Verified 2026-07-24.

- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) — Canonical specification for describing HTTP APIs; current published specification is linked from this stable URL.
- [Zalando RESTful API Guidelines](https://github.com/zalando/restful-api-guidelines) — Actively maintained, CC BY-licensed production conventions from a large API estate.
- [Google API Improvement Proposals](https://google.aip.dev/general) — First-party design guidance used across Google APIs.
- [RFC 9457: Problem Details for HTTP APIs](https://www.rfc-editor.org/rfc/rfc9457.html) — IETF Standards Track definition that supersedes RFC 7807.
- [GraphQL Specification](https://spec.graphql.org/) — Normative language-independent GraphQL contract.
- [gRPC Core Concepts](https://grpc.io/docs/what-is-grpc/core-concepts/) — First-party explanation of services, calls, streaming, metadata, and deadlines.
- [OWASP API Security Project](https://owasp.org/www-project-api-security/) — Authoritative API threat model used to shape authorization and resource limits.
