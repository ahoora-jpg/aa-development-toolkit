# Multi-tenant SaaS Sources

Verified 2026-07-24.

- [AWS Well-Architected SaaS Lens](https://docs.aws.amazon.com/wellarchitected/latest/saas-lens/saas-lens.html) — First-party framework for tenant isolation, identity, onboarding, operations, and SaaS tradeoffs.
- [AWS SaaS Lens: General design principles](https://docs.aws.amazon.com/wellarchitected/latest/saas-lens/general-design-principles.html) — Concise primary guidance on tenant-aware identity, isolation, metrics, automation, and noisy-neighbor controls.
- [Azure multitenant architecture guide](https://learn.microsoft.com/azure/architecture/guide/multitenant/overview) — First-party cloud architecture guidance comparing multitenant design approaches.
- [Azure multitenant storage and data approaches](https://learn.microsoft.com/azure/architecture/guide/multitenant/approaches/storage-data) — First-party comparison of shared, sharded, and dedicated data isolation models.
- [Apptension SaaS Boilerplate](https://github.com/apptension/saas-boilerplate) — Active, MIT-licensed implementation example used only to cross-check common SaaS application concerns.
