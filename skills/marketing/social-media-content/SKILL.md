# Social Media Content Design

Status: Draft
Last reviewed: 2026-07-26

## Purpose

How to design visual content for social platforms (Instagram, TikTok, LinkedIn) that stays recognizably on-brand while fitting each platform's culture and format — directly extends the visual system defined in `skills/design/branding/` and `skills/design/design-systems/` onto social channels.

## Core Concepts To Apply

- **One brand kit, adapted per platform**: lock in the same logo, color palette, and one display + one body font across every platform (a simple, documented "social brand kit"), but adapt tone and format to each platform's culture — a formal LinkedIn post and a casual TikTok clip can both be recognizably the same brand without using identical content.
- **Design for thumbnail scale first**: text and key visual elements must read clearly at small, fast-scrolling sizes on a phone — bold, high-contrast type and simple compositions outperform delicate or busy layouts that only look good at full size.
- **Limit to two fonts across all social graphics**: one display/headline font for impact, one clean body font for supporting text — matches the same expressive-display-plus-restrained-body pairing already established in `skills/ui-ux/typography-color-2026/`.
- **Export at each platform's native size, not one reused image**: e.g. Instagram portrait feed posts, Stories/Reels, and Pinterest pins each have different recommended dimensions — resizing one generic image for every platform produces awkward crops and weaker performance than exporting for each format.
- **Reusable templates over one-off designs**: build a small set of templates (product feature, testimonial, promotional announcement) matching the brand's design system, so content can be produced quickly and consistently rather than redesigned from scratch each time — critical for a small team without a dedicated designer for every post.
- **Consistency sustained over time beats trend-chasing**: a recognizable, stable visual style maintained for months builds more brand recognition than constantly switching to whatever aesthetic is trending that week — treat trend awareness (`skills/ui-ux/typography-color-2026/`, `skills/ui-ux/tactile-brutalism/`) as an occasional refresh, not a weekly change.

## When To Use

Build the social content templates once the core brand kit (`skills/design/branding/`) and design system (`skills/design/design-systems/`) are finalized, so social content stays visually anchored to the same source rather than drifting into its own separate look over time.

## External Sources

Both sources above are external — the Instagram brand resource center is official platform documentation (subject to Meta's own usage terms), and Google Fonts is an actively maintained open font collection; link to both rather than duplicating their content.
