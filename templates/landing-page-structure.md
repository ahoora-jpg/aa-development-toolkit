# Template: Landing Page Structure

Status: Approved
Last reviewed: 2026-08-05
Source: Original (this repo)

Generic, product-agnostic page structure. Use with
`prompts/build-landing-page.md`.

```
1. Navbar (components/navbar/COMPONENT.md)
2. Hero
   - Headline (1 sentence, benefit-first)
   - Subheadline (1-2 sentences)
   - Primary CTA + secondary CTA (optional)
   - Hero visual (image/illustration/3D — see skills/ui-ux/motion-scroll-driven)
3. Social proof strip (logos or short stat row) — optional, high-value if available
4. Feature/benefit section (3-4 items, icon + short title + 1 sentence each)
5. Detailed showcase (1-3 sections alternating image/text sides)
6. Testimonials or case study snippet — optional
7. Pricing or comparison (if applicable)
8. FAQ (also improves SEO/agent-legibility — see skills/seo/SKILL.md)
9. Final CTA (repeat primary action)
10. Footer (links, contact, legal, social)
```

## Notes

- Sections 3, 6, and 8 are optional — include only what's true and
  available; empty/fake social proof hurts trust more than omitting it.
- Keep the hero above the fold on mobile without requiring scroll to see
  the primary CTA.
