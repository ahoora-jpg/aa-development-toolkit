# Coding Standards

Status: Approved
Version: 1.0.0

## General

- Write clear and maintainable code.
- Prefer simple solutions over clever abstractions.
- Keep functions focused on one responsibility.
- Avoid duplicated logic.
- Remove dead, temporary, and commented-out code.
- Preserve existing project conventions.
- Do not add dependencies without a documented benefit.

## Security

- Validate external input.
- Sanitize data before processing or storage.
- Escape output for its destination context.
- Never commit secrets, credentials, tokens, or private keys.

## Definition of Done

Code must be working, verified, maintainable, secure, documented where necessary, and free of temporary code.
