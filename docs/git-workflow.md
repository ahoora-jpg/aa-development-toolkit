# Git Workflow

Status: Approved
Version: 1.0.0

## Core Rules

- Keep commits small and focused.
- Commit related changes together.
- Review changes before committing.
- Keep the main branch stable.
- Never commit secrets or private information.
- Pull remote changes before starting work on another computer.

## Standard Workflow

1. Run git status.
2. Pull remote changes.
3. Make one focused change.
4. Review the diff.
5. Stage related files.
6. Commit with a clear message.
7. Push to the remote repository.

## Commit Messages

Use clear messages such as:

- Add accessibility standards
- Document WordPress security rules
- Update component approval workflow
