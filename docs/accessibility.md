# Accessibility Standards

Status: Approved
Version: 1.0.0

## Core Requirements

- Use semantic HTML.
- Ensure all interactive elements work with a keyboard.
- Maintain a visible focus indicator.
- Give controls clear accessible names.
- Associate form fields with labels.
- Provide meaningful alternative text for informative images.
- Do not communicate meaning through color alone.
- Maintain sufficient color contrast.
- Use a logical heading hierarchy.
- Respect reduced-motion preferences.

## Verification

- Test keyboard-only navigation.
- Check visible focus states.
- Review form labels and error messages.
- Test zoom and responsive layouts.
- Check reduced-motion behavior.
