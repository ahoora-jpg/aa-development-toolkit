# SEO Standards

Status: Approved
Version: 1.0.0

## Core Requirements

- Use semantic and crawlable HTML.
- Maintain a logical heading hierarchy.
- Provide descriptive titles and metadata.
- Use meaningful internal links.
- Provide useful alternative text for informative images.
- Avoid essential content that depends entirely on JavaScript.
- Maintain stable and descriptive URLs.

## Technical SEO

Review canonical URLs, indexing directives, XML sitemaps, structured data, redirects, broken links, mobile usability, performance, duplicate content, filtering, and pagination.
