# Web Design Source Registry

Status: Active
Version: 1.0.0
Last reviewed: 2026-07-22

This registry contains reviewed open-source design sources for reusable website components.

## Selection Rules

A source may be approved when:

- Its license permits reuse.
- Its architecture is understandable.
- Its visual effect can be isolated.
- It does not force a framework migration.
- It can be adapted to semantic HTML.
- It has acceptable performance.
- It supports responsive layouts.
- It does not damage accessibility.
- Its source and license are documented.

## Compatibility Levels

- Native: usable with HTML, CSS, and vanilla JavaScript.
- Adaptable: requires extraction from React, Vue, or another framework.
- Inspiration only: visual reference; code should not be copied directly.
