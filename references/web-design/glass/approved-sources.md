# Approved Glass UI Sources

Last reviewed: 2026-07-22

## GlassKit

Repository:
https://github.com/JUNGHERZ/GlassKit

License:
MIT

Technology:
HTML and CSS, with minimal JavaScript.

Strengths:

- Pure CSS
- No framework dependency
- Design tokens
- Light and dark modes
- Mobile-first
- Reusable component classes
- Suitable for WordPress themes

Approved uses:

- Header surfaces
- Navigation containers
- Buttons
- Product cards
- Badges
- Search panels
- Modal surfaces

Decision:
Primary glass UI reference for Safari Home.

## Oat Glassed

Repository:
https://github.com/good-lly/oat-glassed

License:
MIT

Technology:
Semantic HTML, CSS, vanilla JavaScript and Web Components.

Strengths:

- Zero dependencies
- Small bundle
- Semantic markup
- Keyboard-aware components
- Progressive enhancement

Decision:
Secondary reference for accessibility and semantic component structure.

## liquidGL

Repository:
https://github.com/naughtyduk/liquidGL

Technology:
WebGL and html2canvas.

Strengths:

- Real-time refraction
- Glossy liquid-glass appearance
- Interactive tilt
- GSAP compatibility

Risks:

- Additional runtime work
- WebGL dependency
- html2canvas dependency
- Not appropriate for widespread use

Decision:
Experimental only. Test on one CTA or floating control before adoption.
