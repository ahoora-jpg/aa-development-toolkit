# Safari Home Visual Feature Shortlist

Status: Proposed
Version: 1.0.0

## Phase 1 — Safe visual upgrade

1. Glass sticky header
2. Glass primary CTA
3. Soft gradient and noise background
4. Product-card depth hover
5. GSAP Hero text reveal
6. Subtle image parallax
7. Reduced-motion fallback

## Phase 2 — Premium interaction

1. Floating navigation state
2. Magnetic CTA on desktop
3. Animated category transitions
4. Brand-logo marquee with pause controls
5. Featured-product spotlight

## Phase 3 — Controlled 3D prototype

1. Lazy-loaded Three.js Hero
2. Static fallback image
3. Mouse-responsive rotation
4. Mobile simplified rendering
5. Performance comparison against the current Hero

## Rejected for now

- Full React migration
- Full-screen 3D on every page
- Heavy cursor replacement
- Continuous WebGL backgrounds
- Excessive blur across large surfaces
- Long preloader animations
- Copying complete templates without adaptation
