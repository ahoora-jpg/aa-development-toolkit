# Examples

Status: Approved
Last reviewed: 2026-08-05

Full, self-contained reference pages combining multiple skills/tokens/
components at once — for any AI assistant to see how the pieces fit
together, rather than reading each skill in isolation. Generic/category-
agnostic; not tied to any specific project or product.

## Files

- **`landing-page.html`** — generic landing page. Demonstrates: design
  tokens, dark mode toggle, accessible sticky navbar, CSS-native
  scroll-reveal motion, `prefers-reduced-motion` handling, semantic HTML.
- **`catalog-page-rtl.html`** — generic RTL/Farsi catalog listing page.
  Demonstrates: RTL layout with logical CSS properties, Farsi typography,
  filter sidebar + responsive grid pattern, mirrored directional icon
  convention.

Open either file directly in a browser to view it — no build step
required.
