# Testing and Quality Sources

Verified 2026-07-24.

- [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) — Detailed practitioner reference for balancing unit, integration, contract, and end-to-end tests.
- [Testcontainers for Java](https://github.com/testcontainers/testcontainers-java) — Active, MIT-licensed reference implementation for tests against disposable real dependencies; its underlying approach is language-independent.
- [k6](https://github.com/grafana/k6) — Active load-testing project for scripted performance checks and CI integration.
- [Google SRE: Testing for Reliability](https://sre.google/sre-book/testing-reliability/) — First-party production guidance connecting tests, failure, and reliable operations.
- [OWASP ASVS](https://github.com/OWASP/ASVS) — Active security verification standard useful for deriving testable application-security requirements.
