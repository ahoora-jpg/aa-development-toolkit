# DevOps and Deployment Sources

Verified 2026-07-24.

- [Docker build best practices](https://docs.docker.com/build/building/best-practices/) — Current first-party guidance for small, rebuildable, secure container images.
- [Moby](https://github.com/moby/moby) — Active, Apache-2.0-licensed upstream container engine project used to verify implementation terminology.
- [Trunk Based Development](https://trunkbaseddevelopment.com/) — Focused practitioner reference for short-lived branches, frequent integration, and release patterns.
- [Conventional Commits](https://www.conventionalcommits.org/) — Maintained specification for machine-readable commit intent.
- [OpenTelemetry Specification](https://opentelemetry.io/docs/specs/otel/) — Current vendor-neutral specification for traces, metrics, logs, resources, and context propagation.
- [Google Site Reliability Engineering book](https://sre.google/sre-book/table-of-contents/) — Primary guidance for monitoring, release engineering, automation, and reliable operations.
- [DevOps Exercises](https://github.com/bregman-arie/devops-exercises) — Active, widely used practical material for cross-checking operational topic coverage.
