# Backend Architecture Sources

Verified 2026-07-24.

- [Awesome Software Architecture](https://github.com/mehdihadeli/awesome-software-architecture) — Active, CC0-licensed map of architecture patterns and authoritative follow-up material.
- [Ardalis Clean Architecture](https://github.com/ardalis/CleanArchitecture) — Active, MIT-licensed implementation reference showing dependency inversion in a production-oriented template.
- [DDD Starter Modelling Process](https://github.com/ddd-crew/ddd-starter-modelling-process) — Active community resource for collaborative bounded-context and domain discovery.
- [Microservices by Martin Fowler and James Lewis](https://martinfowler.com/articles/microservices.html) — Influential primary explanation of service characteristics and operational tradeoffs.
