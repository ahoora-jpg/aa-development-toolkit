# Scalability and Performance Sources

Verified 2026-07-24.

- [Google Site Reliability Engineering book](https://sre.google/sre-book/table-of-contents/) — Primary production guidance on SLOs, capacity planning, overload, cascading failures, and load balancing.
- [AWS Builders' Library](https://aws.amazon.com/builders-library/) — First-party operational patterns for retries, timeouts, backoff, load shedding, and resilient scaling.
- [Redis documentation](https://redis.io/docs/latest/) — First-party reference for cache behavior and Redis data structures.
- [k6](https://github.com/grafana/k6) — Actively maintained load-testing project with production-oriented test and metric workflows.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) — Active, widely reviewed overview used to cross-check scaling and caching terminology.
