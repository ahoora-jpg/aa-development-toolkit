# Real-time and Event-driven Sources

Verified 2026-07-24.

- [RFC 6455: The WebSocket Protocol](https://www.rfc-editor.org/rfc/rfc6455.html) — IETF Standards Track definition of WebSocket framing, lifecycle, origin, and security behavior.
- [WHATWG HTML: Server-sent events](https://html.spec.whatwg.org/multipage/server-sent-events.html) — Living web-platform specification for `EventSource` and SSE wire behavior.
- [CloudEvents Specification](https://github.com/cloudevents/spec) — Active, Apache-2.0-licensed CNCF specification for interoperable event metadata.
- [AsyncAPI Specification](https://github.com/asyncapi/spec) — Active, Apache-2.0-licensed contract specification for asynchronous APIs.
- [Apache Kafka](https://github.com/apache/kafka) — Active upstream Apache-licensed distributed event-log implementation.
- [RabbitMQ Server](https://github.com/rabbitmq/rabbitmq-server) — Active upstream broker implementation and authoritative product reference.
- [NATS Server](https://github.com/nats-io/nats-server) — Active, Apache-2.0-licensed upstream messaging server.
